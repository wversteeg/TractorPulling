# data

TOML definitions for tractors, engines, tires, sleds and classes (`sleds/`: a sled set-up with its weight box, push-down distance and chain; `classes/`: the technical limits of a pulling class, such as NTTO standard 3.5 t). Values are documented in their natural units (e.g. rpm, metric hp) and converted to SI on load. Files are added with the corresponding Milestone 1 components.
